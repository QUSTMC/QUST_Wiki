## 1.拉取源代码

1. 安装[git](https://git-scm.com/)

   克隆仓库:

    ```pwsh
    mkdir qustwiki
    cd qustwiki
    git clone https://github.com/QUSTMC/QUST_Wiki.git
    ```

2. 切换到dev分支
    :::danger
    必须进行这一步，否则你的改动可能无法正常上传
    :::

    ```pwsh
    git switch dev
    ```

## 2.进入编辑

1. 安装[VS Code](https://code.visualstudio.com/)

2. 切换成中文

3. 打开文件夹
    详细编辑教程请看

## 3.本地浏览器预览

1. 安装git插件（安装完成之后应该出现绿色标记处图标）

2. 登录你的github账号并确保你有仓库的编辑权限（可以找Aure要）

3. 安装[nvs](https://github.com/jasongin/nvs/releases)

4. 安装Node.js

   :::note
   在VS Code中按Ctrl+`(键盘左上角的~)打开终端
   :::

   ```pwsh
   nvs add lts
   ```

   之后使用

   ```pwsh
   nvs
   ```

   手动选择版本即可

5. 打开开发服务器:

    ```pwsh
    npm run dev
    ```

    之后在浏览器访问`http://localhost:4321/`
    你在VSC的改动保存后会被自动同步到浏览器

## 4.提交PR 等待同步

:::note
这是你做的改动上线的最后一步，请完全确认你的改动没有问题
:::

1. 点击源代码管理

2. 在更改中简要描述你都做了什么，之后点击`提交` 以及 `同步更改`

3. 点击`创建拉取请求(PR)` 并提交请求，审核通过后过两分钟你就可以在链接中看到你贡献的文档了！
